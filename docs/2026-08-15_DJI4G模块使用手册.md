# DJI 4G 模块（DJ4Hub）本地使用手册

> 本手册基于 DJ4Hub（https://github.com/WongLoki/DJ4Hub）的实际安装与使用经验整理。DJ4Hub 是一个非官方开源项目，未获 DJI 授权，仅供个人学习与非商业用途。

## 一、适用范围

本手册适用于：

- 第一代 DJI 4G 模块（常见 USB VID/PID 为 `0x2CA3:0x4006`）
- 实际识别为 `BAIWANG` / `Quectel` 的模块（VID/PID `0x2C7C:0x0125`，俗称 EG25/QDC507 方案）
- Apple Silicon Mac（M 系列芯片），macOS 13 Ventura 或更新版本
- 想通过 USB 在 Mac 上实现：查看状态、收发短信、管理 eSIM、USB 4G 上网、AT 调试

## 二、硬件与系统要求

| 项目 | 要求 |
|------|------|
| 模块 | 受支持的 DJI 4G 模块 |
| SIM 卡 | 可用实体 SIM，或兼容的实体 eUICC/eSIM 卡 |
| 数据线 | 支持数据传输的 USB-C 线缆（仅充电线不行） |
| Mac | Apple Silicon（Intel 未经验证） |
| 系统 | macOS 13+ |
| 依赖 | 官方 Release 无需安装 Go/Homebrew；源码编译需要 Go + libusb |

## 三、两种安装方式

### 方式一：官方 Release（推荐，适合 0x2CA3:0x4006 模块）

1. 访问 [DJ4Hub Releases](https://github.com/WongLoki/DJ4Hub/releases)
2. 下载名称包含 `DJ-4G-Hub-macOS-arm64` 的 ZIP
3. 解压后执行：
   ```bash
   ./install
   ```
4. 程序默认安装到 `/usr/local/libexec/dj4ghub`，命令入口在 `/usr/local/bin/dj4ghub`

### 方式二：源码编译 + Patch（适合 0x2C7C:0x0125 Baiwang/EG25 模块）

官方 Release 目前只识别 DJI 自己的 USB ID `0x2CA3:0x4006`。如果你的模块识别为 `BAIWANG`（VID/PID `0x2C7C:0x0125`），需要打 patch 后编译。

> 本手册对应的 Patch 版本仓库：https://github.com/thejimkeen/DJI4G.git
> 已经包含了对 `0x2C7C:0x0125` 的支持，可以直接克隆这个仓库而不用再手动打 patch。

#### 3.1 克隆源码

直接克隆已打 patch 的仓库：

```bash
git clone --recurse-submodules https://github.com/thejimkeen/DJI4G.git /tmp/DJI4G
cd /tmp/DJI4G
```

或从原仓库手动打 patch：

```bash
git clone --recurse-submodules https://github.com/WongLoki/DJ4Hub.git /tmp/DJ4Hub
cd /tmp/DJ4Hub
# 然后按下方 3.2 节手动修改源码
```

#### 3.2 应用 Patch

修改两个文件：

**`cmd/dj4ghub-macos/usbat_darwin.go`**

将常量区从：
```go
const (
	djiUSBVendorID  = 0x2ca3
	djiUSBProductID = 0x4006
)
```
改为：
```go
const (
	djiUSBVendorID      = 0x2ca3
	djiUSBProductID     = 0x4006
	quectelUSBVendorID  = 0x2c7c
	quectelUSBProductID = 0x0125
)
```

将 `openDJIUSBAT()` 中的设备打开逻辑从：
```go
handle := C.libusb_open_device_with_vid_pid(ctx, djiUSBVendorID, djiUSBProductID)
if handle == nil {
	C.libusb_exit(ctx)
	return nil, errors.New("DJI USB AT device 2ca3:4006 not found")
}
```
改为：
```go
handle := C.libusb_open_device_with_vid_pid(ctx, djiUSBVendorID, djiUSBProductID)
if handle == nil {
	handle = C.libusb_open_device_with_vid_pid(ctx, quectelUSBVendorID, quectelUSBProductID)
}
if handle == nil {
	C.libusb_exit(ctx)
	return nil, errors.New("DJI/Quectel USB AT device not found")
}
```

**`cmd/dj4ghub-macos/main.go`**

将 `discoverDJIUSBDevice()` 中的过滤条件从：
```go
if !okVendor || !okProduct || vendorID != 0x2ca3 {
```
改为：
```go
if !okVendor || !okProduct || (vendorID != 0x2ca3 && vendorID != 0x2c7c) {
```

#### 3.3 编译

```bash
cd /tmp/DJ4Hub
./scripts/build-macos.sh
```

编译产物位于 `/tmp/DJ4Hub/dist/dj4ghub-macos-arm64`。

#### 3.4 可选：安装到系统 PATH

```bash
sudo mkdir -p /usr/local/bin
sudo cp /tmp/DJ4Hub/dist/dj4ghub-macos /usr/local/bin/dj4ghub
```

之后就可以像官方 Release 一样用 `dj4ghub start` / `dj4ghub activate`。

## 四、快速开始

### 4.1 连接模块

1. 把 SIM/eSIM 卡插入模块卡槽
2. 用支持数据传输的 USB-C 线将模块连接到 Mac
3. 等待模块上电完成（通常几秒到十几秒）

### 4.2 激活 USB 网卡模式（一次性）

首次使用或模块处于短信模式（`usbnet=0`）时，需要先激活上网模式：

```bash
dj4ghub activate
```

或源码二进制：
```bash
/tmp/DJ4Hub/dist/dj4ghub-macos -activate
```

成功输出示例：
```
已检测到模块：BAIWANG Baiwang（2c7c:0125）
当前 usbnet=0，正在写入 ECM 上网模式 1...
正在软重启模块以触发 macOS 重新枚举网卡...
激活完成：en17，IP 192.168.225.28
```

激活完成后，Mac 会出现一个 USB 网卡（如 `en17`），并拿到 `192.168.225.x` 网段 IP。

### 4.3 启动网页控制台

```bash
dj4ghub start
```

浏览器会自动打开：
```
http://127.0.0.1:7575
```

如果只想启动服务而不自动开浏览器，或指定端口：
```bash
dj4ghub start --listen 127.0.0.1:8080
```

### 4.4 停止服务

```bash
dj4ghub stop
```

## 五、工作模式说明

| 模式 | `usbnet` 值 | 用途 | 说明 |
|------|-------------|------|------|
| 短信模式 | 0 | 状态、短信、eSIM、AT 调试 | 默认模式，不上网 |
| 上网模式 | 1 | 向 macOS 暴露 USB 网卡 | 可蜂窝上网 |
| 实验模式 | 2/3 | 未验证 | 不推荐日常使用 |

切换模式会触发 USB 重新枚举，网页会短暂显示断开，属正常现象。不要在 eSIM Profile 写入过程中拔出模块或切换模式。

## 六、网页控制台功能

打开 `http://127.0.0.1:7575` 后，可以看到：

### 6.1 概览
- 运营商、信号强度、LTE 注册状态
- SIM 状态、当前工作模式
- 实时上下行速度、本次运行累计流量
- 联网活动：应用 → 隧道 → USB 网卡 → 蜂窝的链路还原

### 6.2 短信
- 接收、发送短信
- 自动轮询
- 验证码自动提取
- 长短信分片
- 国际号码使用完整格式，如 `+86138XXXXXXXX`

### 6.3 eSIM / 卡片
- 读取、下载、启用、改名、删除 eSIM Profile
- 管理插在模块卡槽中的兼容实体 eUICC 卡片
- **注意**：不是 Mac 内置 eSIM

### 6.4 网络
- 查看 macOS 是否识别 USB 网卡
- 物理接口、默认出口、蜂窝 IP
- PDP/APN 信息
- 4G 出口与代理检测

### 6.5 AT 调试
- 直接向模块发送 AT 指令
- 仅用于诊断和开发
- **不要执行来源不明的刷机/写入指令**

## 七、常用命令参考

```bash
# 启动并自动打开管理页面
dj4ghub start

# 启动无硬件演示模式
dj4ghub start --demo

# 一次性激活 USB 网卡模式
dj4ghub activate

# 停止服务
dj4ghub stop

# 查看运行状态
dj4ghub status

# 查看实时日志
dj4ghub logs

# 重新打开管理页面
dj4ghub open
```

源码二进制直接使用 flag：
```bash
/tmp/DJ4Hub/dist/dj4ghub-macos -listen 127.0.0.1:7575      # 启动服务
/tmp/DJ4Hub/dist/dj4ghub-macos -demo -listen 127.0.0.1:7575 # 演示模式
/tmp/DJ4Hub/dist/dj4ghub-macos -activate                    # 激活上网
```

## 八、故障排查

### 8.1 报错：未检测到受支持的 DJI 4G 模块（USB 2ca3:4006）

可能原因：
- 模块未插好或使用的是充电线
- 模块 VID/PID 不是 `0x2CA3:0x4006`，而是 `0x2C7C:0x0125`
- 模块未上电

排查步骤：
```bash
# 查看 USB 设备
system_profiler SPUSBDataType

# 或查看串口
ls -la /dev/cu.*
```

如果看到 `BAIWANG` / `Quectel` 设备但没有串口，说明需要按“方式二”源码编译 + patch。

### 8.2 报错：no Quectel/DJI USB serial ports found

如果同时看到 `USB AT bridge opened` 日志，这只是一条提示信息，不影响使用。DJ4Hub 已经通过 libusb 直接和模块的 AT 口通信，不需要 `/dev/cu.*` 串口。

### 8.3 激活后没有 IP，或无法上网

1. 确认 SIM 卡已开通数据业务且有流量
2. 检查 APN 设置是否正确
3. 查看 macOS 网络设置中 USB 网卡是否拿到 `192.168.225.x` IP
4. 尝试重新插拔模块并再次 `dj4ghub activate`

### 8.4 网页打不开

1. 确认服务已启动：`dj4ghub status`
2. 手动访问 `http://127.0.0.1:7575`
3. 检查是否有其他程序占用了 7575 端口

### 8.5 模式切换后网页断开

正常现象。模块切换 `usbnet` 后会重新枚举 USB，等待 10-30 秒后刷新页面即可。

## 九、数据与隐私

- 管理服务和网页默认只监听 `127.0.0.1:7575`，不对外暴露
- SIM、短信、EID、ICCID、网络连接信息不会主动上传到远程服务器
- 发布 Issue 或日志前，请隐藏手机号、验证码、EID、ICCID、IMSI 等个人信息

本地数据目录：
```
~/Library/Logs/DJ 4G Hub/dj4ghub.log
~/Library/Application Support/DJ 4G Hub
```

## 十、注意事项

1. **许可证**：DJ4Hub 主项目使用 **PolyForm Noncommercial License 1.0.0**，仅限非商业用途。
2. **硬件风险**：eSIM Profile 写入、模式切换、AT 调试等操作会真实修改模块状态，操作前请确认。
3. **签名**：当前发行包使用临时签名，尚未经过 Apple Developer ID 公证，首次运行可能需要在“系统设置 → 隐私与安全性”中允许。
